# Easy Text 2026 (v3)

Geometry Nodes typography and text animation for **Blender 5.2 LTS**: node-group assets
(work as a modifier without any add-on) plus an optional extension for a font picker,
multi-line text, presets, and camera and light rigs.

Status: Phase 2 in progress. Node group `ET Text Mesh` (text → clean mesh with extrusion, bevel, materials, UVs,
per-letter animation) and the control panel `Easy Text`, the v3 of the v2.1 GUI: four settings nodes inside the
node editor.
Analysis of the previous version: `docs/01-analysis-v2.1.md`, target picture: `docs/02-target-v3.md`,
development rules and API pitfalls: `docs/03-development.md`, architecture: `docs/04-architecture-v3.md`,
node layout rules: `docs/05-node-layout.md`.

## Testing in Blender (5.2 LTS)

1. Download `assets/easytext_v3_demo.blend` and open it. It opens in the workspace "Easy Text": the camera view
   on top, the node editor with the control panel directly below, the properties editor on the modifier tab.
   A text object with the modifier, a camera and two area lights are set up.
2. Two ways to operate the tool, same nodes inside:
   - `Easy Text` (the demo): the control panel in the node editor, laid out like the v2.1 GUI and in the user's
     order. Three settings nodes carry every control as a widget: **1. Text Input** (four line fields),
     **2. Font Settings** (font, size, alignment, spacing, text box), **3. Mesh Settings** (shape with bevel
     switch, materials, UV switch; plate and outline folded away) and **4. Animation** (timing, move, rotate,
     scale, reveal, bounce; output folded away), a tip box under each, a note with the export hint. Four wires
     with markers, nothing else to connect.
   - `ET Text Mesh`: one node group with inputs as modifier panels: Text (4 lines), Typography (font socket, size,
     alignment, spacing, text box), Shape (depth, bevel, smooth angle), Material, UV, Animate, Outline, Output.
3. For your own file: File → Append → `easytext_v3.blend` → NodeTree → `ET Text Mesh` or `Easy Text`.
   Alternatively register the `assets/` folder as an asset library in the Preferences; both groups then show up in
   the Add Modifier menu under "Easy Text".
4. Add a Geometry Nodes modifier to any mesh object (or, since 5.2, an empty) and pick the group.

What the group guarantees (verified headless): a closed, manifold mesh without duplicate vertices; caps as n-gons or
triangles; sides and bevel as quads; a `UVMap` with planar caps and one continuous, undistorted UV band for sides and
bevel (U = contour length, V = arc length over back bevel, side, front bevel); materials in the slots Front/Side/Bevel;
warnings for empty text and a bevel that is too wide.

Plate (switch **Plate**): a rounded base plate behind the text, sized from the text plus margins or by hand, with
thickness, a bevelled rim, a gap to the text and an optional relief that rises around the letters; own UVMap and
material slot. The v2.1 "Beveled Plate" without the dense grid.

Scene: the demo file comes with a **camera orbit** (a path around the text, Follow Path with a keyframed offset,
Track To the text) and a **light rig**: the node group `ET Light Rig` on an Empty instances three light objects
(key, fill, rim) around the target and aims them, with angle, elevation and distance per light. Instanced lights
render in Cycles (verified headless) and EEVEE. Both rigs are created by `easytext_build.rigs`, which the extension
reuses.

Animation (switch **Animate**): every letter, word or line gets its own local time from Start, Duration, Stagger and
Order (left to right, right to left, centre out, random), an easing (linear, ease in/out, in-out, overshoot) and a
loop mode, and travels from its start state (Offset, Rotation, Scale around the glyph, word, line or text pivot)
into place, or away with Direction = Out. Hide Before Start gives a typewriter reveal, Bounce a continuous wobble.
Driven by the scene frame, no keyframes needed.

## Layout

| Path | Content |
|---|---|
| `src/easytext_build/` | Builder: generates every node group from scripts (source of truth). |
| `src/easytext_build/groups/` | One file per node group. |
| `assets/easytext_v3.blend` | Built asset library (never edit by hand). |
| `assets/easytext_v3_demo.blend` | Demo scene for a quick look. |
| `assets/blender_assets.cats.txt` | Asset catalog. |
| `assets/snapshots/*.json` | Text snapshots of the node groups for diffs and reviews. |
| `docs/screenshots/` | Node editor screenshots of every group and of the demo workspace (regenerated by `demo_ui`). |
| `tools/dump_blend.py` | Reads a .blend without Blender (for reference files). |
| `docs/` | Analysis, target picture, development rules, architecture, reference dumps of v2.1. |

## Building

Requires Python 3.13 (like Blender 5.2). The `bpy` wheel is Blender as a Python module (~400 MB), pinned to 5.2.0.

```bash
python -m pip install -e ".[dev,bpy]"
python -m easytext_build.build     # builds assets/easytext_v3.blend, the demo, catalog and snapshots
python -m easytext_build.smoke     # loads the file, attaches the modifier, checks the result
pytest                             # tests without Blender
```

The window layout of the demo file (workspace, editors, camera view) needs a real Blender window; headless Blender
does not keep such changes. With a Blender 5.2.0 installation and a display (or Xvfb):

```bash
xvfb-run -a -s "-screen 0 1920x1080x24 +extension GLX" blender assets/easytext_v3_demo.blend \
    --python-expr "import sys; sys.path.insert(0, 'src'); import easytext_build.demo_ui as d; d.main()"
```

This also writes the screenshots under `docs/screenshots/`.

Alternatively with a Blender installation:

```bash
blender -b --python-expr "import sys; sys.path.insert(0, 'src'); import easytext_build.build as b; b.main()"
```
